# 📚 Мой читательский дневник

## 📊 Статистика года
```dataview
TABLE WITHOUT ID
	length(rows) as "Книг прочитано",
	round(average(rows.rating), 1) as "Средняя оценка"
WHERE type = "book" AND status = "Прочитано" AND dateformat(date_finished, "yyyy") = "2026"
GROUP BY true
```

---

## 📖 Сейчас читаю
```dataview
TABLE WITHOUT ID
	join(author, ", ") as Автор,
	file.link as Книга,
	dateformat(date_started, "dd.MM.yyyy") as "Начал"
WHERE type = "book" AND status = "Читаю"
SORT date_started ASC
```

## ✅ Прочитано в этом году
```dataview
TABLE WITHOUT ID
	join(author, ", ") as Автор,
	file.link as Книга,
	rating as Оценка,
	dateformat(date_finished, "dd.MM.yyyy") as "Закончил"
WHERE type = "book" AND status = "Прочитано" AND dateformat(date_finished, "yyyy") = "2026"
SORT date_finished DESC
```

## 📋 В планах
```dataview
TABLE WITHOUT ID
	join(author, ", ") as Автор,
	file.link as Книга,
	genre as Жанр
WHERE type = "book" AND status = "В планах"
SORT file.ctime DESC
```

## 🎲 Случайная книга
```dataviewjs
const pages = dv.pages().where(p => p.status == "Прочитано" && p.type == "book")
if (pages.length > 0) {
	const random = pages[Math.floor(Math.random() * pages.length)]
	dv.paragraph(`📖 **${random.file.link}** — ${random.author} (${random.rating}/10)`)
} else {
	dv.paragraph("*Нет прочитанных книг*")
}
```
