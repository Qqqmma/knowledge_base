# Родительный падеж в грузинском языке

Существительные в родительном падеже отвечают на вопросы **ვის (кого?)** и **რის (чего?)**. В этом падеже **возможны 2 окончания: -ის, -ს.**

Выбор окончания зависит от того согласная или гласная основа у существительного.

Если существительное имеет **согласную основу**, то в родительном падеже у него будет окончание -ის:

| Именительный падеж | Родительный падеж | Перевод            |
| ------------------ | ----------------- | ------------------ |
| დავიდ**ი**         | დავიდის           | Давид / Давида     |
| ადამიანი           | ადამიანის         | человек / человека |
| ამინდი             | ამინდის           | погода / погоды    |

Если основа слова заканчивается на **-ა** или **-ე** - то в родительном падеже эти конечные гласные опускаются и к слову прибавляется окончание **-ის**:

| Именительный падеж | Родительный падеж | Перевод           |
| ------------------ | ----------------- | ----------------- |
| მთვარე             | მთვარის           | луна / луны       |
| თვე                | თვის              | месяц / месяца    |
| ავსტრია            | ავსტრიის          | Австрия / Австрии |
| მაგიდა             | მაგიდის           | стол / стола      |

Во всех остальных случаях в родительном падеже будет окончание **-ს**:

| Именительный падеж | Родительный падеж | Перевод           |
| ------------------ | ----------------- | ----------------- |
| გიორგი             | გიორგის           | Георгий / Георгия |
| უთო                | უთოს              | утюг / утюга      |
| ბუ                 | ბუს               | сова / совы       |
